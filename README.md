# School ERP - Next Steps

## Stack
- Next.js
- PostgreSQL
- Prisma
- Tailwind CSS
- Zod
- JWT Auth

## Rodando projeto

```bash
docker compose up -d
npm install
npx prisma migrate dev
npm run dev
```

## URLs
- Frontend: http://localhost:3000
- API: http://localhost:3000/api/alunos
- Prisma Studio: npx prisma studio
